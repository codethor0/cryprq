# CI Templates

Hardened CI workflow templates extracted from CrypRQ.

## Templates

- `ci.yml` - Main CI workflow with quick-check, build, security, governance
- `e2e-tests.yml` - E2E test suite workflow
- `ci-stabilizer.yml` - CI health scanning and maintenance
- `stability-monitor.yml` - Daily stability monitoring

## Usage

Copy templates to `.github/workflows/` and customize:
- Repository-specific paths
- Tool versions
- Job configurations
