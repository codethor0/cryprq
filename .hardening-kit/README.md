# Universal Hardening Kit

**Purpose:** Reusable toolkit for hardening repositories (CrypRQ, SecAlign, and future projects)

## Contents

### CI Templates
- Hardened CI workflow templates
- Security scanning configurations
- Governance shield templates

### Docker Templates
- E2E test suite templates
- Docker Compose configurations
- Test runner images

### Scripts
- Rust/Node/Python hardening scripts
- Governance shield
- Stability monitor

### Documentation Templates
- README templates
- Security documentation templates
- Contributing guidelines

## Usage

Apply hardening to a new repository:

1. Copy CI templates to `.github/workflows/`
2. Copy Docker templates to `docker/e2e/`
3. Copy scripts to `scripts/`
4. Update documentation templates
5. Run hardening validation

## Status

This kit is extracted from CrypRQ hardening process and can be applied to other repositories.
