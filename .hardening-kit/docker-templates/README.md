# Docker Templates

Docker E2E test suite templates.

## Templates

- `Dockerfile` - E2E test runner image
- `docker-compose.e2e.yml` - E2E test orchestration
- `test_suite.sh` - Main test runner script
- `tests/` - Test case templates

## Usage

Copy to `docker/e2e/` and customize:
- Service names
- Test cases
- Network configurations
