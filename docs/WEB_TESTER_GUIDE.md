# Portal testing guide

The current browser interface is the authenticated file-transfer portal.
The former Listener/Dialer dashboard, VPN toggle, scenario panels, and saved
browser diagnostics are no longer the default application.

Use [Web UI Guide](WEB_UI_GUIDE.md) for pairing and transfers,
[Docker Web Guide](DOCKER_WEB_GUIDE.md) for independent devices, and
[Portal validation](WEB_VALIDATION_RUN.md) for executable acceptance checks.
Historical v1.0.x release records describe an earlier unauthenticated preview.
They do not establish the behavior of the current portal.
